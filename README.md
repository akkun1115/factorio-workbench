# Factorio Workbench — 使い方

Factorio通常版のレシピ図鑑・材料ツリー・生産比率・生産計画を確認できるWebアプリです。

## 起動とインストール

- **スマホのPWA**：GitHub PagesのHTTPS公開URLをChromeで開き、「アプリをインストール」または「ホーム画面に追加」を選びます。インストール済みならホーム画面のアイコンから開きます。
- **PCのPWA**：同じ公開URLをブラウザで開きます。アプリをインストールできる場合はアドレスバーのインストール項目から追加できます。
- **オフラインHTML**：`Factorio_Workbench_オフライン_v15.html`をブラウザで直接開きます。インストール・通信は不要です。
- **GitHub Pagesへの配置**：公開用ZIPを展開して、中にある`index.html`、`sw.js`、`pwa-register.js`、`manifest.webmanifest`、`icons/`などをリポジトリの公開ルートに置きます。`Settings → Pages`から`main / (root)`を指定します。
- **更新**：PWAをオンラインで起動し、更新の案内が出たら「更新」を押します。お気に入りなどのデータを保護するため、再インストールやアプリデータの削除は行わないでください。

## ホームと検索

ホームの検索欄で製品名・読み・ローマ字を入力します。誤字検索も利用できます。前回の続き、最近見た製品、お気に入りからも開けます。使用頻度が高い機能は上位に並びます。

## レシピ図鑑

- **まとめ**：直接の必要材料・設備の台数比・関連レシピ・使用先を表示します。必要材料の`＋`を押すと、さらに材料を展開できます。
- **生産比率**：完成品の設備台数を`−`と`＋`で変更できます。「自動」「自動2」「自動3」で比率候補を選べます。設備カードの数字は切り上げ台数で、理論値は小数を含む設備台数です。
- **スマホのまとめ**：直接材料の設備だけを初期表示します。各カードの「上流を見る」を押すと、材料を作るための設備や原料を確認できます。
- **材料ツリー**：素材を段階的にたどります。アイコンから該当レシピへ移動できます。
- **類似レシピ**：材料の共通点から関連製品を探します。
- **逆引き**：選んだ材料がどのレシピに使われるかを確認します。
- **レーン検索**：材料を追加して製造候補を検索します。追加履歴と材料カテゴリは折りたため、開閉状態が保持されます。
- **手持ち材料**：所持数を入力して製造可能な製品を確認します。

## 生産計画

複数製品の生産目標、設備・モジュール設定を入力して必要設備と材料を計算します。モジュールや設備は「設備・モジュール設定」で変更できます。

## 保存・バックアップ

お気に入り、履歴、計画、設定はブラウザ内に保存します。「使い方・設定」の「設定・計画を書き出す」からJSONでバックアップできます。同じ画面の「保存したデータを読み込む」から復元できます。オフラインHTMLとPWAの間では保存領域が異なるため、JSONを使って移行してください。

## 注意

- PCとスマホの保存内容は自動同期されません。
- 複数出力や確率処理などの一部レシピは、材料供給の計算方法に制約があります。
- オフライン起動には初回オンラインアクセスとキャッシュ保存が必要です。HTML単体版は最初からオフラインで利用できます。
