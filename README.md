# Factorio Workbench v0.14

Factorio通常版の製造レシピ図鑑・材料ツリー・生産比率計算・レーン検索を、PCとスマートフォンで使えるオフライン対応Webアプリです。レシピ192件と画像を内蔵しています。

## 何が変わった？

### スマートフォンのみ（PCの表示は変更なし）

- **まとめ／生産比率**：設備カードを横2列から**縦1列**に変更。
- **まとめ**：「関連レシピ」「この製品の使い道」を**横2列**で表示。
- **材料ツリー／逆引き**：選択中レシピの表示と「変更」ボタンをスマホ幅に収めるよう修正。
- **類似レシピ**：横長テーブルをカード表示に変え、**関連度％を常に右上**に表示。横スクロール不要。

### PC・スマホ共通

- **レーン検索**：「選択中レシピの材料を入れる」「クリア」を上側へ移動。
- **材料追加**：「履歴」→「基本素材」→「回路・加工品」→「化学・流体」→「物流・その他」の順番。
- **カテゴリの折りたたみ**：見出し横の矢印で開閉。初回は「履歴」と「基本素材」だけ開き、操作後の開閉状態は次回も維持。
- **履歴から追加**：一度選んだレーン材料を履歴の先頭に保存（最大18件）。選択中の材料は候補から除外され、クリア後に再び履歴から追加できます。
- **設定の引き継ぎ**：レーン選択材料、材料履歴、各カテゴリの開閉状態もJSONバックアップに含めました。

## インストール・起動

### POCO F6などのAndroid（PWAとしてインストール）

1. `site/` の**中身**をGitHub PagesなどのHTTPSサイトにアップロードします。
2. 公開されたURLを**Chrome**で開き、「アプリをインストール」または「ホーム画面に追加」を選びます。
3. オンラインで初回起動すると、アプリ・アイコンがオフライン用に保存されます。
4. 2回目以降はホーム画面のアイコンから起動します。オフラインキャッシュが残っていれば、ネットがなくても利用できます。

**注意：** ZIPを端末に保存しただけではPWAのインストールはできません。Web上での公開が必要です。今回のZIPには公開先URLは含まれていません。

### PC／単体HTML

`standalone/Factorio_Workbench_オフライン_v14.html`（または別添の同名HTML）を開くだけで利用できます。Web公開不要、ネット接続不要です。単体HTMLはPWAのインストール・更新通知には対応しません。

## GitHub Pagesへの公開方法

1. GitHubでリポジトリを作成します（例：`factorio-workbench`）。
2. **「GitHub Pages公開用ZIP」**を展開し、`index.html`、`sw.js`、`manifest.webmanifest`、`pwa-register.js`、`icons/`、`.nojekyll`をリポジトリのルートへアップロードします。
3. `Settings → Pages → Build and deployment → Deploy from a branch → main / (root)` に設定します。
4. 発行されたHTTPSのURLを端末で開いてください。

以前v0.13を公開済みなら、同じ公開先のファイルをv0.14に更新してください。Service Workerのキャッシュ名は `factorio-workbench-v0.14.0` へ変更済みです。オンライン状態で新版を検出すると、更新ボタンから切り替えられます。

## 主な使い方

| 機能 | 操作 |
|---|---|
| レシピ図鑑 | 製品名・ひらがな・ローマ字で検索し、画像や候補をクリック |
| まとめ | 必要材料と製造設備の台数比を確認 |
| 生産比率 | 完成品の設備数を±で変更、自動・自動2・自動3を選択 |
| 材料ツリー | 必要材料を段階的に展開 |
| 類似レシピ | 共通材料・関連度で候補を検索 |
| 逆引き | 選んだ材料が使われる製品を検索 |
| レーン検索 | 材料を追加し、製造候補を絞り込み。履歴を再利用 |
| ホーム | 前回開いた製品・タブを再開、お気に入り・最近の製品を表示 |

## データ保存と移行

お気に入り、最近見た製品、レーン材料履歴・折りたたみ状態、生産目標、手持ち材料などはブラウザに保存されます。

- **バックアップ**：「使い方・設定」→「設定・計画を書き出す」でJSON保存。
- **復元**：同じ画面の「保存したデータを読み込む」でJSONを選択。
- **旧HTML→PWA**：保存領域が異なるため**自動移行しません**。旧HTMLから書き出したJSONをPWAへ読み込んでください。
- **v0.13 PWA→v0.14 PWA**：同じURL・ドメインなら通常は保存データを引き継げますが、公開前のJSONバックアップを推奨します。

## ディレクトリ

- `site/`：PWA公開用（HTML・マニフェスト・Service Worker・アイコン）
- `standalone/`：単体HTML版
- `source/`：HTML組込用JavaScript、CSS、計算エンジン、レシピ・画像データ
- `tests/`：計算・画面・PWA処理の検証スクリプト
- `プレビュー_*.png`：PC／スマホ画面の表示確認画像

## 技術的な注意点

- モジュールや上流設備の理論値は既存の計算仕様を維持しています。複数出力・確率・循環を含む工程など、一部は外部供給として扱います。
- PWAのインストール、Service Worker登録と更新はHTTPS配信が前提です。実機POCO F6でのv0.14インストール確認は未実施です。
- 画像・レシピにはゲーム素材が含まれます。公開する際は利用条件を確認してください。
