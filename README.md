# Factorio Workbench — 使い方

Factorio通常版2.xのレシピ192件・生産比率・小技74件を調べる日本語Webアプリです。レシピ・アイコン・説明・Tipsを内蔵し、オフラインで使えます。

## アプリを開く

- **PC・スマホのPWA版**：GitHub Pagesの公開URLをブラウザで開きます。Android Chromeの場合は「アプリをインストール」または「ホーム画面に追加」を選びます。
- **単体HTML版**：`Factorio_Workbench_オフライン_v19.html` をブラウザで開くだけで利用できます。Web公開は不要です。
- **更新**：新しい版の公開後、PWAの更新案内が出たら「更新」を選びます。最新版への切り替えはインターネット接続が必要です。

## 小技・Tipsの探し方

1. 左メニュー（スマホは≡）の **小技・Tips** を開きます。
2. 「搬送ベルト」「回路・制御」「鉄道」「電力」などのカテゴリを選ぶか、検索欄へ「地下ベルト」「コピー」「在庫」などを入力します。
3. カードの **手順・注意点を見る** を押すと、やり方・注意点・関連アイテム・出典リンクが開きます。
4. ☆を押してお気に入り登録すると、**★ 保存済み** からまとめて読めます。
5. 「関連アイテム」を押すと、その製品のレシピ図鑑へ移動します。

## アイテムの説明に載っている小技

- レシピ一覧・図鑑上部の **ⓘ** を押すと、製品の説明・効果に加えて「関連する小技」が表示されます。
- **レシピ詳細** タブの「概要・効果」でも関連Tipsを確認できます。
- 小技のタイトルを押すと、専用のTipsメニューで手順が開きます。
- PCではⓘにカーソルを重ねると、説明のプレビューと関連Tipsのタイトルが見られます。スマホはタップして情報パネルを開きます。
- 関連小技がない製品では、無関係なTipsを無理に表示しません。

## レシピ・生産比率など

- **まとめ**：直接材料・完成品と材料の設備台数・関連レシピ・使い道を確認します。
- **生産比率**：完成品の台数を変え、製造時間・設備速度・材料の生成数を考慮して上流設備数を再計算します。
- **材料ツリー**：製造工程を階層表示します。
- **レーン検索**：複数の材料から作れるレシピを探します。最近選んだ材料も再利用できます。
- **類似レシピ・逆引き・生産計画**：画面上部のタブやメニューで切り替えます。
- 一部の特殊工程は、上流計算で外部供給として扱う場合があります。

## 保存とバックアップ

- 最近見た製品、お気に入り、Tipsの★登録などは、この端末のブラウザ内に保存されます。
- **使い方・設定**からJSONバックアップを保存・読み込みできます。機種変更・PCとスマホ間の引き継ぎに利用してください。
- 端末や公開URLが違う場合、保存データは自動同期されません。

## 小技の出典と適用範囲

- 日本語・英語の **Factorio Wiki** と日本語攻略Wikiの記事を調べ、操作や工場設計に役立つ74件を日本語で整理しました。
- 各カードに元の情報ページへのリンクを付けています。モッドや設定・ゲームの更新によって一部の挙動が異なる場合があります。
- スマホで遊ぶFactorioを想定した手順ではなく、ゲーム本体のPC版のデフォルト操作（Q・Ctrl・Shiftなど）を説明しています。

## GitHub Pagesの公開・更新

1. `Factorio_Workbench_v019_GitHubPages公開用.zip` を展開します。
2. 中の `index.html`、`sw.js`、アイコンなど、すべてのファイルを公開中のGitHubリポジトリの同じ位置に上書きします。
3. GitHub Pagesの公開を確認し、オンラインでアプリを起動します。
4. スマホのインストール済みアプリを再起動し、更新案内があれば適用します。

公開時はゲーム内画像・名称の利用条件を公開者自身で確認してください。
