# Factorio Workbench — 使い方

Factorio通常版2.xのレシピ・生産比率・関連アイテムを調べられるWebアプリです。ゲーム内のアイコンを内蔵しています。

## 開く・インストール

- **PC**：GitHub Pagesで公開したURLをChromeやEdgeで開きます。
- **Android**：公開URLをChromeで開き、メニューから「アプリをインストール」または「ホーム画面に追加」を選択します。
- **単体HTML版**：`Factorio_Workbench_オフライン_v18.html` をブラウザで開きます（インストール不要）。

PWA版は初回起動時に通信が必要です。アプリの必要ファイルが保存されると、通信できない場所でも使えます。更新の案内が出た場合は「更新」を押して切り替えます。

## 製品の説明と効果

- **PCのレシピ一覧**：各レシピのⓘへカーソルを合わせると、その場に短い説明が表示されます。クリックすると詳しい情報を確認できます。製品のカード本体をクリックすると従来どおり図鑑へ移動します。
- **PCのレシピ図鑑**：製品名の横のⓘにカーソルを合わせると、説明・効果のプレビューが出ます。ⓘをクリックすると詳細パネルを開きます。
- **スマホ**：ⓘをタップすると画面下から説明・効果のパネルを開きます。×で閉じられます。
- **レシピ詳細タブ**：説明・数値効果・主な使用先を図鑑の中で確認できます。

全192レシピに、用途や特徴の短い日本語説明を収録しています。数値効果は検証できた設備・モジュール・搬送ベルトなどに限り記載します。すべてのアイテムで数値効果があるわけではありません。生産時間・材料数は既存のレシピ情報で確認できます。

## 製造計画

- **まとめ**：必要材料と完成品・材料の設備数を表示します。
- **生産比率**：完成品の設備数を変更すると、材料と上流工程に必要な設備数を再計算します。
- **材料ツリー**：製造に必要な材料を階層的に表示します。
- **類似レシピ・逆引き**：使う材料が近いレシピ、特定の素材を使う製品を探します。
- **レーン材料検索**：材料を複数選択し、その材料から製造可能な製品を検索します。以前選んだ材料は履歴から再追加できます。

一部の特殊レシピ（複数出力・確率など）は、上流計算で外部供給として扱うことがあります。

## 履歴・お気に入り・バックアップ

ホームで最近の製品、前回の続き、お気に入りを確認できます。設定画面のデータ保存機能でJSONを出力・読み込みできます。端末を替えたり単体HTML版からPWA版へ移行したりする場合は、JSONバックアップを利用してください。保存領域はブラウザと公開URLごとに独立しています。

## GitHub Pagesへ公開する

「GitHub Pages公開用ZIP」の**中身**を、現在公開しているリポジトリの同じ位置に上書きします。Pagesの設定が有効なら、次回更新チェック時にアプリ側へ更新案内が出ます。レシピのアイコンなどゲーム素材の公開条件は、公開者が確認してください。
