# Factorio Workbench — 使い方

## 起動

GitHub Pages の公開 URL を Chrome で開きます。スマホではブラウザのメニューから「アプリをインストール」または「ホーム画面に追加」を選択できます。初回起動にネット接続が必要です。以降は必要なファイルが保存され、オフラインでも利用できます。

## 図鑑で情報を見る

1. ホームの検索で製品を選びます。
2. 製品名の右の **ⓘ** を押すと、短い説明・効果・使用先を確認できます。閉じるには **×** またはダイアログの外を押します。
3. **レシピ詳細** タブでは、情報を展開したまま製法・研究条件と一緒に確認できます。
4. 数値効果は原則として通常品質・通常版の値です。必要に応じて出典リンクを開けます。

現在、個別の説明・効果を詳しく収録しているのは **発展基板 / 組立機2 / 速度モジュール1 / インサータ** です。それ以外の製品は、レシピ情報から主な使用先を表示します。データは段階的に拡充します。

## ほかの主な機能

- **まとめ**: 必要材料と設備比率を確認。スマホの上流工程は「上流を見る」から展開できます。
- **生産比率**: 完成品の設備数を設定して、直接材料と上流工程の必要設備数を確認します。
- **材料ツリー**: 製造工程をさかのぼります。
- **類似レシピ / 逆引き**: 近い製法や使用先を探します。
- **レーン検索**: 材料候補を選んで関連するレシピを検索します。材料履歴も利用できます。
- **ホーム**: 前回の続き、履歴、お気に入りから再開できます。

## データの保存・移行

「設定・データ保存」から JSON バックアップの保存と復元ができます。HTMLファイル版・PWA版・別端末では保存領域が異なるため、必要に応じてバックアップを使って移行してください。

## 配布方法

`site/` 内のファイルを、そのまま GitHub Pages の公開ルートにアップロードします。公開 URL には HTTPS を使ってください。既に公開済みなら、その内容を上書きしてください。公開時にはアイコンなどのゲーム素材の利用条件を確認してください。
